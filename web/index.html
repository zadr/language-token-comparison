Every language, adjusted for task difficulty

No task is solved in all languages, so a plain average would reward languages that only solve easy tasks. Each language gets a fixed-effects estimate instead: log(tokens) = task effect + language effect, fit over all task/language pairs. The "typical task" column gives that estimate as a token count for a task of average difficulty. The ± value and whisker show one standard error. The dot track uses a log scale.
